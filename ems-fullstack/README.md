# Frontend — Employee Management System

React + Vite frontend for the Employee Management System.

See the [project README](../README.md) for the full overview, and
[SETUP.md](../SETUP.md) for run instructions.

## Quick reference

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build
npm run lint     # eslint, zero-warning tolerance
```

Environment variable: `VITE_API_URL` (see `.env.example`) — points the app
at the backend API. Defaults to `http://localhost:8080/api` for local dev.
